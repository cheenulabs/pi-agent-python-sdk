**Patch release: more reliable blocking burst delivery, observation stop, and usability fixes on top of 0.2.0.**

## Fixed

### Blocking finite-burst delivery

Ready blocking consumers now receive the full ready queue in each thread crossing instead of stopping at 64 records. Queue count and byte limits are unchanged; overflow for genuinely slow consumers remains explicit ([#66](https://github.com/cheenulabs/pi-agent-python-sdk/pull/66), [#36](https://github.com/cheenulabs/pi-agent-python-sdk/issues/36)).

[RPC backpressure →](https://github.com/cheenulabs/pi-agent-python-sdk/blob/v0.2.1/docs/rpc.md#output-bursts-and-backpressure)

### Stream and input edge cases

- Sequential `aiter` / `async for` reuse on the same async stream no longer raises a busy error; concurrent readers and result-drain conflicts are still rejected ([#62](https://github.com/cheenulabs/pi-agent-python-sdk/pull/62), [#58](https://github.com/cheenulabs/pi-agent-python-sdk/issues/58)).

- Locally rejected, unsent input leaves a healthy client reusable without weakening ownership for commands that may have reached Pi ([#61](https://github.com/cheenulabs/pi-agent-python-sdk/pull/61), [#57](https://github.com/cheenulabs/pi-agent-python-sdk/issues/57)).

## New Features

### Stop observation without closing Pi

Call `stop()` on an observation context, drain remaining buffered records, then inspect `status.end_reason` for scoped stop, discard, overflow, or process termination ([#69](https://github.com/cheenulabs/pi-agent-python-sdk/pull/69), [#56](https://github.com/cheenulabs/pi-agent-python-sdk/issues/56)).

[Scoped observation example →](https://github.com/cheenulabs/pi-agent-python-sdk/blob/v0.2.1/examples/scoped_output.py)

## Documentation and compatibility
