**Pi 1.5.0 compatibility and additional wire metadata for the community Python SDK.**

## Upgrade notes

Pi **1.5.0** replaces 1.4.0 as the reviewed and tested runtime. Users of `strict_version=True` must align their separately installed Pi runtime with 1.5.0 when upgrading the SDK. The minimum remains **0.85.1**; other recognized versions at or above the minimum remain allowed by default with `compatibility="untested"` ([#109](https://github.com/cheenulabs/pi-agent-python-sdk/pull/109)).

No Python call-site changes are required. RPC commands and event discriminators are unchanged; the new metadata fields are optional.

[Compatibility policy →](https://github.com/cheenulabs/pi-agent-python-sdk/blob/v0.2.7/docs/compatibility.md)

## Additional wire metadata

Typed command source metadata now includes optional `SourceInfo.changelogPath`. Usage cost metadata includes optional `totalFromProvider`: true identifies a provider-reported billed total; false or absent means a catalog estimate. Component costs remain estimates and need not sum to a provider-reported total. The SDK preserves the supplied total and raw metadata rather than recalculating billing amounts.

[Wire annotations →](https://github.com/cheenulabs/pi-agent-python-sdk/blob/v0.2.7/docs/api.md#events-and-wire-types)

## Pi-owned runtime changes

Pi 1.5.0 updates tool schema/coercion, summary authentication handling, session persistence and provider behavior. These remain Pi responsibilities, not Python SDK implementations. The SDK's development dependencies and CI action pins were also refreshed ([#111](https://github.com/cheenulabs/pi-agent-python-sdk/pull/111), [#105](https://github.com/cheenulabs/pi-agent-python-sdk/pull/105), [#107](https://github.com/cheenulabs/pi-agent-python-sdk/pull/107), [#110](https://github.com/cheenulabs/pi-agent-python-sdk/pull/110)).

[Reviewed upstream changes →](https://github.com/cheenulabs/pi-agent-python-sdk/blob/v0.2.7/docs/discovery.md#pi-150-update)

## Requirements and installation

| Requirement | Version |
| --- | --- |
| Python | **3.11+** |
| Pi protocol baseline (tested) | **1.5.0** |
| Pi protocol minimum | **0.85.1** |
| Node.js for Pi 1.5.0 | **22.19.0+** |

```sh
python -m pip install --upgrade pi-agent-python-sdk==0.2.7
npm install -g @earendil-works/pi-coding-agent@1.5.0
```

Import the Python package as `pi_agent`. Configure Pi separately with your provider and model; upgrading this Python package does not install or upgrade Pi.
