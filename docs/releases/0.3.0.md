**New coding-agent imports and an experimental Pi Durable backend for the community Python SDK.**

## Coding-agent namespace

Use the explicit `pi_agent.coding` namespace for coding-agent clients. These are the same classes as the existing top-level imports, which remain supported without warnings. Upgrade the installed package before changing imports; `pi_agent.coding` is not available in 0.2.7 ([#127](https://github.com/cheenulabs/pi-agent-python-sdk/pull/127), [#132](https://github.com/cheenulabs/pi-agent-python-sdk/pull/132)).

```sh
python -m pip install --upgrade pi-agent-python-sdk==0.3.0
```

```python
from pi_agent.coding import PiClient, AsyncPiClient
```

[Quick start →](https://github.com/cheenulabs/pi-agent-python-sdk/blob/v0.3.0/README.md#quick-start)

## Experimental Pi Durable

`pi_agent.durable` adds synchronous and async clients for upstream Pi Durable: idempotent submissions, bounded watches and crash recovery. This is a Python API around the original TypeScript/Node.js runtime, not a Python port. Python runtime dependencies remain empty ([#127](https://github.com/cheenulabs/pi-agent-python-sdk/pull/127)).

Durable is experimental and supports Linux/macOS, not Windows. It requires an explicit caller-supplied Node host from the v0.3.0 source checkout with its npm dependencies installed; neither the wheel nor sdist bundles or downloads that host. Existing coding-agent behavior is unchanged.

[Host setup and Durable API →](https://github.com/cheenulabs/pi-agent-python-sdk/blob/v0.3.0/docs/durable.md)

## Compatibility and errors

The tested coding-agent baseline advances from Pi 1.5.0 to **1.5.2**; the minimum remains **0.85.1**. Users of `strict_version=True` must install Pi 1.5.2 separately. `PiCommandError.code` now optionally preserves an upstream command error code.

| Requirement | Version |
| --- | --- |
| Python | **3.11+** |
| Coding-agent baseline (tested) | **1.5.2** |
| Coding-agent minimum | **0.85.1** |
| Node.js for the tested runtimes | **22.19.0+** |
| Experimental Durable baseline | **1.5.2**, caller-supplied host |

```sh
npm install -g @earendil-works/pi-coding-agent@1.5.2
```

Pi owns provider authentication, models, tools and sessions. Installing this SDK does not install or upgrade either runtime.
