# Pi Agent Python SDK 0.1.0

Run Pi from Python with synchronous and asynchronous clients, streamed text,
typed RPC commands, and settled results. Pi runs as a subprocess and keeps its
own models, authentication, tools, extensions, and session storage.

## Install

Requires Python 3.11+, Node.js 22.19.0+, and a separate Pi installation. The
reviewed protocol baseline is Pi 0.85.1.

```sh
npm install -g @earendil-works/pi-coding-agent@0.85.1
python -m pip install pi-agent-python-sdk==0.1.0
```

Run `pi` once to configure your provider and model, then use that configuration
from Python:

```python
from pi_agent import PiClient

with PiClient() as pi:
    result = pi.run("Explain the current project without changing files.")
    print(result.text)
```

## Included

- `PiClient` and `AsyncPiClient` with explicit methods for all 33 Pi 0.85.1 RPC commands.
- Typed wire payloads, future-only event subscriptions, streaming, extension
  dialogs, and results containing session identity and observed usage.
- Owned process lifecycle, bounded I/O and retained messages, cancellation
  cleanup, and preservation of unknown protocol fields and events.
- Zero third-party Python runtime dependencies, nine runnable examples, and
  guides covering configuration, RPC access, errors, and compatibility.

Install the distribution as `pi-agent-python-sdk` and import `pi_agent`.
Users of earlier source checkouts must update their package/import names.
