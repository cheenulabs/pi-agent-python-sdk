**Patch release: record Pi 0.86.1 as the tested protocol baseline on top of 0.2.1.**

## Changed

### Tested Pi baseline 0.86.1

The offline compatibility constants and reviewed source fingerprints now match Pi **0.86.1**. The RPC command vocabulary, JSONL framing, and event serializer are unchanged from 0.86.0; upstream added a Meta Muse provider surface outside the RPC boundary ([#76](https://github.com/cheenulabs/pi-agent-python-sdk/pull/76)).

With this package version, Pi 0.86.1 reports `compatibility="tested"`. Callers that set `strict_version=True` accept 0.86.1 and continue to reject other untested versions. The minimum remains **0.85.1**.

[Compatibility →](https://github.com/cheenulabs/pi-agent-python-sdk/blob/v0.2.2/docs/compatibility.md)

## Compatibility

| Requirement | Version |
| --- | --- |
| Python | **3.11+** |
| Pi protocol baseline (tested) | **0.86.1** |

