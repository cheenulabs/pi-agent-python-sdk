**Patch release: Pi 0.87.0 is the tested protocol baseline for the community Python SDK.**

## Changed

### Tested Pi baseline 0.87.0

The offline compatibility constants and reviewed source fingerprints now match Pi **0.87.0** ([#82](https://github.com/cheenulabs/pi-agent-python-sdk/pull/82)). With this package version, Pi 0.87.0 reports `compatibility="tested"`, and `strict_version=True` accepts it. The minimum remains **0.85.1**; other recognized versions above the minimum remain untested unless reviewed separately.

The typed wire annotations now describe Pi's `context_edit` session entries and optional model image input limits. Context edits can omit or replace earlier content for future provider requests while preserving raw session history. Pi owns that behavior; the Python SDK passes the entry and model fields through. The RPC command and output event vocabulary is unchanged.
