**Pi 1.4.0 compatibility for the community Python SDK, with unchanged RPC commands and Python APIs.**

## Upgrade notes

Pi **1.4.0** replaces 1.3.0 as the reviewed and tested runtime. Users of `strict_version=True` must align their separately installed Pi runtime with 1.4.0 when upgrading the SDK. The minimum remains **0.85.1**; other recognized versions at or above the minimum remain allowed by default with `compatibility="untested"` ([#103](https://github.com/cheenulabs/pi-agent-python-sdk/pull/103)).

No Python call-site changes are required. The RPC command vocabulary, wire shapes, and TypeScript comparison contract are unchanged.

[Compatibility policy →](https://github.com/cheenulabs/pi-agent-python-sdk/blob/v0.2.6/docs/compatibility.md)

## Pi-owned runtime improvements

Pi 1.4.0 improves compaction summaries, recovery of failed tool-call attempts, and extension-tool restoration in resumed sessions. It also updates provider attribution and classifier compatibility. These behaviors stay inside Pi: the SDK continues to wrap its RPC protocol rather than implement provider or agent behavior.

[Reviewed upstream changes →](https://github.com/cheenulabs/pi-agent-python-sdk/blob/v0.2.6/docs/discovery.md#pi-140-update)

## Requirements and installation

| Requirement | Version |
| --- | --- |
| Python | **3.11+** |
| Pi protocol baseline (tested) | **1.4.0** |
| Pi protocol minimum | **0.85.1** |
| Node.js for Pi 1.4.0 | **22.19.0+** |

```sh
python -m pip install --upgrade pi-agent-python-sdk==0.2.6
npm install -g @earendil-works/pi-coding-agent@1.4.0
```

Import the Python package as `pi_agent`. Configure Pi separately with your provider and model; upgrading this Python package does not install or upgrade Pi.
