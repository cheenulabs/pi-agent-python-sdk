# Review specifications

The public implementation specification is [PLAN.md](../../PLAN.md), backed
by [protocol discovery](../discovery.md). Milestone status and PR references
belong in [implementation.md](../implementation.md).

Use GitHub pull requests in `cheenulabs/pi-coding-agent-python-client`.
For each review, pin the previous milestone commit and compare the proposed
branch against it. Review standards from CONTRIBUTING.md separately from
requirements in the plan. A PR need only satisfy its declared milestone;
the final audit must satisfy the complete plan.
